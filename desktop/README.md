# qFin

Desktop companion for FinOS, shaped like qFlipper.

```bash
npm install
npm start
```

Python CLI (no Node):

```bash
pip install pyserial
python3 qfin.py info
python3 qfin.py ls /ext
python3 qfin.py install ../docs/apps/dice.tapp
```

Flashing a merged image uses `python3 -m esptool` (`pip install esptool`).
