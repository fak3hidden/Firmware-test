Install firmware
and qFin.

One wizard: desktop companion for Windows / macOS / Linux, then flash the T-Embed over USB. Chrome or Edge required for the flash step.

  1. 1. Desktop app
  2. 2. Flash firmware
  3. 3. Bluetooth

1. Install qFin

qFin is the qFlipper-style companion: files, CLI, updates, app install.

Windows installer macOS Linux AppImage

From source: cd desktop && npm install && npm start · or python3 desktop/qfin.py

2. Flash firmware

Hold the encoder knob (BOOT) and tap RESET. Pick your board, then flash. You can also jump to the full flasher.

Open the web flasher

3. Pair phone or PC over Bluetooth

On the device: Main menu → Bluetooth → Toggle On. Advertises as Flipper (Nordic UART). Then:

Phone (Web Bluetooth) PC via qFin USB or BLE

Buttons from the phone: U D L R O B. Same file/app protocol as USB.
